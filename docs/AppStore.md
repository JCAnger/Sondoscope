# App Store : brouillons

**Sous-titre** : Les sondages de la présidentielle

**Description** : Sondoscope réunit les sondages d'intentions de vote pour l'élection présidentielle française de 2027 et en calcule une moyenne pondérée, qui privilégie les plus récents. Consultez chaque sondage avec sa méthode et sa notice officielle. Application indépendante, sans lien avec un parti, un candidat ou un institut. Un sondage n'est pas une prédiction.

**Notes pour la revue** : les données proviennent de jeux ouverts publiés sur data.gouv.fr. Aucun compte n'est nécessaire. Pendant le silence électoral, l'app affiche un écran explicatif.

# Politique de confidentialité (brouillon)

Sondoscope ne collecte aucune donnée personnelle. L'app ne contient ni compte, ni publicité, ni outil de suivi. Elle télécharge uniquement un fichier de données public. L'adresse IP est traitée techniquement par l'hébergeur de ce fichier.

À faire relire avant publication.
